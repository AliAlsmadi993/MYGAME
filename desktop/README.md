# نسخة الكمبيوتر (Electron)

```bash
# من المجلد الرئيسي: ابنِ اللعبة كملف واحد وانسخه لهون
npm run build:desktop

# من هاد المجلد
cd desktop
npm install
npm start        # شغّل اللعبة
npm run dist     # اعمل ملف تثبيت (Windows و Linux) بمجلد out/
```

- اللعبة بتطلب بس صلاحيات المايك وقفل الماوس والشاشة الكاملة.
- الربط مع Steam (الإنجازات) بيحتاج حساب Steamworks، وبينضاف لاحقاً.
