# حزمة الأصوات (اختياري)

إذا اللعبة شغّالة على سيرفر (npm run dev، itch.io، GitHub Pages)، حط ملفات الصوت هون،
واكتب أسماءها بـ pack.json، مثلاً:

```json
["scream.mp3", "laugh.ogg", "thunder_1.mp3", "thunder_2.mp3", "rain_loop.ogg"]
```

اسم الملف بيحدد مكانه باللعبة (نفس أسماء خانات «مؤثرات حقيقية» بالاستوديو).
الأسهل لـ play.html: استوديو الأصوات من القائمة ← «استورد ملفات».
