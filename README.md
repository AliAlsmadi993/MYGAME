# السعلوة

لعبة رعب من الفلكلور العربي: الوحش **بيسمعك** من المايك، و**بيتعلّم** أسلوبك وبيتذكّرك بين المحاولات، و**بيتمسخر عليك**، و**بيقلّد صوتك** ليستدرجك.

وثيقة التصميم الكاملة: [GDD.md](GDD.md)

## أسهل طريقة للعب

نزّل الملف **`play.html`** وافتحه بدبل كليك (Chrome أو Edge). ما بيحتاج تثبيت ولا سيرفر.

> لا تفتح `index.html` مباشرة: هاد ملف التطوير وبيحتاج `npm run dev`.

## التشغيل للتطوير

```bash
npm install
npm run dev      # افتح الرابط اللي بيطلع (Chrome أو Edge مستحسن)
npm test         # اختبارات منطق اللعبة
npm run build    # نسخة جاهزة للنشر في مجلد dist/
npm run build:play  # بيحدّث play.html (ملف واحد بينفتح بدون سيرفر)
npm run build:demo  # النسخة التجريبية المجانية (لحد الساعة 2:00) بمجلد dist-demo/
npm run build:desktop  # بيجهّز نسخة الكمبيوتر (شوف desktop/README.md)
```

إضافات للرابط أثناء التطوير: `?debug` بتعرض حالة السعلوة، و`?nomic` بتبدأ بدون مايك، و`?demo` بتجرّب النسخة التجريبية.

## النسخة الأولى (المرحلة 1): شو فيها

- البيت: المدخل، الحوش مع البير، الليوان، المضافة، المطبخ، غرفة الجدة، غرفة الأطفال، الحمّام، والقبو (عرين السعلوة).
- المشي والركض والانحناء، التحمّل واللهاث، والكشاف مع البطارية.
- **المايك:** معايرة (صمت ثم «مين هون؟»)، بوابة ضجيج، ومستويات همس/كلام/عالي/صراخ بمدى سماع مختلف. المخبأ بيكتم الصوت، ودقات الساعة بتغطّي عليه.
- **السعلوة:** تجوّل، تحقّق من الأصوات، تفتيش المخابئ، مطاردة، كمين، تراجع. بتشوف ضوء الكشاف من بعيد، وبتغني تهويدة وهي تتجوّل (إنذار).
- **التعلّم والذاكرة:** بتحفظ مخابئك المفضّلة، طرق هروبك، الغرف اللي بتبلّش فيها، الركض، الكشاف، والصراخ. العادات القديمة بتضعف كل محاولة.
- **التمسخر:** جمل حسب ما عملت فعلاً، مثل «آخر مرة تخبّيت بالخزانة… لسا ريحتك فيها».
- **تقليد صوتك:** بتسجّل مقاطع قصيرة لما تحكي أو تصرّخ، وبعد الساعة 2 بتشغّلها مشوّهة من غرفة ثانية وبتستناك هناك. الساعة 3 بتشغّل أصواتك من كل مكان، ولما تمسكك بتعيد آخر كلمة قلتها.
- 3 أغراض (المسبحة، الخلخال بالقبو دائماً، صورة العائلة). الخلخال بيرنّ وإنت ماشي.
- الفوز بإكمال الطقس بالبير ثم الهروب من البوابة، أو الصمود للفجر.
- 3 مستويات صعوبة، وشاشة نهاية فيها الإحصائيات و«شو تعلّمت السعلوة عنك».

## النسخة الثانية (المرحلة 2): شو انضاف

- **الأغراض الخمسة كاملة:** انضاف مفتاح السحّارة النحاسي وقارورة ماء البير. كل غرض بتحمله بيطلع صوت، والخلخال أكثر شي.
- **مخابئ جديدة:** السحّارة (أأمن مكان بس ما بتشوف شي، وبتفتّشها آخر شي)، الستارة (سريعة بس ضوّك بيفضحك من وراها)، وبيت الخلاء اللي بيتسكّر (بتخبط عليه وممكن تتركه، بس إذا كسرته ما في مهرب).
- **حبس النفَس:** اكبس Space وإنت مخبّى. بيخلّص التحمّل، ولما يخلص بتشهق. إذا قرّبت وإنت بتتنفّس بتسمعك، وإذا فتحت مخبأك وإنت حابس نفَسك في فرصة ما تحسّ فيك (أقل إذا هاد مخبأك المعروف).
- **الحقيبة (4 خانات) والأدوات:** جرس، بطارية، كبريت (ضو صغير ما بيبيّن من بعيد متل الكشاف، وبيولّع الشموع)، ملح (خط عالعتبة ما بتقطعه 45 ثانية)، خرزة زرقاء (بتنجّيك مرة وحدة من إيدها ومعك 5 ثواني تهرب)، ومسجّل كاسيت (بتسجّل صوتك فيه وبتتركه يشتغل لحاله ليشتّتها، وبينفتح بعد أول نجاة).
- **الراديو والتلفون:** شغّل الراديو بالمضافة لتشتّتها، بس بتتعلّم الحيلة بين الليالي. التلفون الأرضي بيرن لحاله: ردّ… ممكن تسمع ستّك، وممكن تسمع صوتك إنت.
- **قدرات جديدة إلها:** بتطفي الشموع وهي ماشية، وبالليلة الثانية بتختفي وبتظهر بمكان ثاني (دايماً بصوت إنذار، وعمرها ما بتظهر جنبك). قرب الفجر بتعمى شوي.
- **مدير التوتر:** مطاردة طويلة بتنتهي بتراجعها وضحكة بعيدة، وإذا الوضع هادي كثير بيصير شي: باب بينصفق، علبة موسيقى بغرفة الأطفال، خطوات فوق السقف (وما في طابق فوق)، الراديو بيشتغل لحاله، التلفون بيرن، همس بأذنك.
- **أشرطة الجدة ودفترها:** 7 أشرطة بتكشف القصة بالتدريج (شريطين جداد كل ليلة). كل شريط بينكتب بدفتر الجدة مع نصيحة، والدفتر بتفتحه من القائمة.
- **النهايات:** الهروب، الفجر (وتلفونك بيرن بصوتك)، الحقيقية (الطقس الكامل + كل الأشرطة)، والسرّية (رجّع الخلخال لعشّها بالقبو بدل البير).
- **الليلة الثانية:** بتنفتح بعد أول نجاة. سعلوة أسرع وأذكى، بتختفي وبتظهر، وبتطفي الشموع أكثر، وخزانة مسكّرة بمسامير. ومكان بدايتها بيتغيّر كل ليلة.
- **الصعوبة الرابعة «بلا رحمة»:** بلا مؤشرات وبلا خرزة، والموت بيمسح ذاكرتها كلها.
- **12 إنجاز** (ولا كلمة، صوتك مش إلك، غيّرت عادتك، ستّي كانت محقّة، وغيرهم) محفوظين بالدفتر.
- **الإعدادات:** حساسية الماوس، عكس المحور، تقليل الومضات، تقليل الصراخ المفاجئ، إخفاء مؤشر المايك، و**وضع الستريمر** (تنبيه قبل تشغيل أي تسجيل من صوتك).
- شاشة تحذير بالبداية، وزر **شارك** بشاشة النهاية بيعمل صورة بطاقة للنتيجة.

- **الأبواب:** كل باب بينفتح وبيتسكّر (E). الباب المسكّر بيحجب نظرها وبيكتم صوتك، بس فتحه وسكّره بيطلع صوت. هي بتفتح الأبواب وهي ماشية (صرير = إنذار)، وأحياناً بتسكّر باب وراها وبتغيّر طريق هروبك.
- **أبواب مقفلة ومفاتيح:** كل ليلة في باب أو أكثر مقفول (حسب الصعوبة، وزيادة بالليلة الثانية). مفاتيحها دايماً بمكان بتوصله بدون ما تفتح قفل. هي ما بيوقفها قفل: بتعدّي من الباب المقفول بخرمشة وهمس.
- **السطح:** درج حجر بزاوية الحوش. فوق في خزان مي (مخبأ آمن، بس بدّك ثانية ونص لتطلع عليه ورشّة المي بتنسمع)، وحبل غسيل عليه شراشف بتتحرّك، والقرية نايمة تحت. قارورة ماء البير ممكن تكون عالسطح. والسعلوة بتطلع وبتنزل الدرج وراك.
- **رسومات الأطفال** عالحيطان بغرفة الأطفال والقبو.
- **الطابق الفوقاني:** درج خشب بزاوية الليوان. فوق في ممر خشبي بيصرّ تحت رجليك (حتى وإنت منحني أحياناً) وتحت رجليها كمان، وغرفة الخياطة فيها مكنة خياطة ومانيكان بتلف لتطلّع عليك لما ما تكون شايفها، والسدّة فيها كراتين ومهد بيهتز لحاله. في خزانة وصندوق للاختباء، والمسبحة والصورة والمفتاح ممكن يكونوا فوق. ما في قمر فوق: عتمة كاملة إلا شمعة وحدة.
- **أبواب بطيئة أو سريعة:** إذا كنت منحني (C) بتفتح الباب وبتسكّره ببطء وبصمت، بس بتوقف ثانية. واقف: بسرعة وبصوت.
- **زجاج مكسور** بأماكن معيّنة (المطبخ، المدخل، فوق): الدعسة عليه بتنسمع من بعيد.
- **المراية بغرفة الجدة** بتعكس فعلاً… وأحياناً لما تطلّع فيها بتشوفها واقفة وراك. لما تلف ما في حدا.
- **سلوك أذكى وأخوف:**
  - الكشاف بوجهها: بتوقف ثانية وبتغطي وجهها بإيديها، وبعدها بتعرف مكانك بالضبط.
  - الكشاف بيرمش لما تقرّب (إنذار)، ولما تفوت على غرفة ممكن تطفي كل شموعها مرة وحدة، وكشافك كمان لثانيتين إذا كنت فيها.
  - البرق ممكن يكشف طيفها واقفة بمكان ما بتتوقعه. وإذا كنت هادي كثير، بتحاول تفاجئك بظهور مفاجئ (بعد لحظة صمت) لتطلّع صوت.
  - إذا دايماً بتتخبّى بنفس المكان، ممكن تفوت هي جوّاه وتستناك (بتسمع نفَسها إذا قرّبت).
  - أحياناً بتزحف، وأحياناً بتمشي عالسقف، وبتنزل بخبطة لما تبلّش تصيد.
  - الشمعة اللي بتولّعها بتجذبها للغرفة.
  - إذا فاجأتك وإنت خايف كثير، بتطلع منك شهقة غصب عنك.
  - إذا بتصرّخ كثير بتقلّد صرخاتك أكثر. وبتصنّف تسجيلاتك: صرخة، ضحكة، نفَس، كلام. ضحكتك القديمة بترجعلك مشوّهة، وبتبلّش الليلة الجديدة بصوتك من الليلة الماضية.
- **الطابع العربي:** مشربيات خشب على نص الشبابيك، صور عائلية قديمة عالحيطان (بوحدة منها الجدة شابة ومعها امرأة طويلة)، ولوحات خط عربي بأمثال وشعر.
- **الواجهة:** خلفية القائمة هي البيت من برّا تحت المطر مع شباك بيضوي وبينطفي وبرق. شاشة الإيقاف فيها: كمّل، الإعدادات، اترك الليلة.
- **إعدادات جديدة:** مستوى الصوت العام وصوت السعلوة والأجواء، السطوع، الحبيبات، ارتجاف الصورة، **ترجمة للأصوات المهمة** مع اتجاهها (مثل «[باب انصفق — يمين]»)، و**تغيير كل الأزرار**.
- **الميلان (Q شمال، R يمين):** بتطلّع من ورا الزوايا، بس راسك ممكن يبيّن.
- **الصوت:** نغمات عود منخفضة ومشوّهة وقت الخطر، وصمت متعمّد قبل الأحداث الكبيرة.
- **اللهجات:** السعلوة بتحكي شامي أو خليجي أو عراقي أو مصري (من الإعدادات). القراءة الآلية بتستعمل صوت اللهجة إذا متصفحك عنده.
- **للستريمرز:**
  - **آخر لحظات كفيديو:** فعّلها من الإعدادات، وبنهاية الليلة بيطلع زر بينزّل آخر 15–20 ثانية (صورة وصوت اللعبة) كملف WebM. التسجيل بيضل على جهازك.
  - **تصويت جمهور تويتش:** اكتب اسم قناتك بالإعدادات، والمشاهدين بيصوّتوا بالشات كل 40 ثانية: `!ضو` (اطفي الكشاف)، `!غني` (خلّيها تغني)، `!باب` (سكّر أقرب باب)، `!خوف` (حدث مخيف). اللعبة بتقرأ الشات بس بدخول مجهول، بدون حساب. اكتب `test` لتجرّب بتصويت وهمي.
- **إعدادات المايك:** الحساسية، اختيار الجهاز (بوضع الستريمر بدون أسماء الأجهزة)، وإعادة المعايرة. ولغة صوت السعلوة: عربي أو English (الترجمة دايماً بالثنتين).

- **تقنياً:** المايك صار يشتغل بـ AudioWorklet (أسرع وما بيعلّق اللعبة)، مع بديل للمتصفحات القديمة.
- **النسخة التجريبية (للـ itch.io و Steam Next Fest):** بتخلص الساعة 2:00 بشاشة خاصة، وبدون الليلة الثانية وبلا رحمة.
- **نسخة الكمبيوتر (Electron)** بمجلد `desktop/`: جرّبتها وبتشتغل مع المايك.
- **سياسة الخصوصية:** بملف [PRIVACY.md](PRIVACY.md) وبشاشة من القائمة.

### لسا لاحقاً
- تسجيلات ممثلة حقيقية بدل القراءة الآلية (باللهجات الأربعة).
- تصويت جمهور يوتيوب (بدّه مفتاح API)، وربط Steamworks (بدّه حساب Steam).
- تجربة على Firefox وSafari (جرّبت على Chromium و Electron بس).

## الخصوصية

- تسجيلات الصوت بتضل **على جهاز اللاعب فقط** (IndexedDB)، وما بتنرفع لأي مكان، وبتنحذف تلقائياً بعد 7 أيام.
- بالقائمة في زر لحذف كل التسجيلات، وزر لمسح ذاكرة السعلوة، وخيار للعب بدون مايك أو بدون تسجيل.
- مسجّل الكاسيت بيسجّل بس لما تستعمله إنت، وبينحذف مع نهاية الليلة.
- دفتر الجدة والإنجازات والإعدادات محفوظين على جهازك (localStorage)، ومنفصلين عن ذاكرة السعلوة.

## الرسوم والصوت

- **مواد واقعية (PBR)** مولّدة برمجياً بدون ملفات: جص مقشّر برطوبة، حجر، بلاط شامي مزخرف، خشب، حجارة مرصوفة، سجاد.
- **إضاءة:** كشاف بظلال حقيقية ونقشة عدسة، ضوء قمر بظلال بيدخل من الحوش، شموع بترجف، وبرق.
- **مؤثرات سينمائية:** توهّج، حبيبات فيلم، زوايا معتمة، وتشويه ألوان بيزيد مع الخوف.
- **السعلوة:** ثوب ممزّق، شعر طويل بيغطي وجهها، إيدين وأصابع طويلة، أقدام معكوسة، وعيون بتلمع.
- **أصوات رعب مولّدة:** صرخة وضحكة وهمس بصوت أنثوي مشوّه، تنفّس وخرخرة لما تقرب، تهويدة مهمهمة، صرير خشب، نقط مي بالقبو، رعد، عواء كلاب، نغمة فزع لما تشوفك، وخطوات حسب الأرضية.
- جهازك ضعيف؟ ضيف `?low` للرابط (بدون ظلال ودقة أقل).

## ملاحظات

- صوت السعلوة وهي تحكي جمل كاملة حالياً قراءة آلية من المتصفح (Text-to-Speech). المطلوب لاحقاً تسجيلات ممثلة حقيقية.
- مصمّمة للكمبيوتر، والموبايل غير مدعوم بهالمرحلة.
